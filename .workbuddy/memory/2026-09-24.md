
## 开屏改为两段式：幕布期先上 WELCOME，开场等整站就绪（用户反馈）
- 用户要求「先出现 welcome 但是等加载完再出现」→ 实现：
  ① 幕布期（整站还在加载）：.is-cover —— 纯黑幕布 + WELCOME 静态在位，
     TO/南洛'S BLOG 隐藏、光斑 opacity:0 且不跑动画、「点一下跳过」不出。
     元素上行内兜底 style（fixed/inset/#000/z-index:100000）防 CSS 晚到闪白。
  ② 开场（load+fonts+page-loader 退场+idle）：openGate 撤 .is-cover、加 .is-shown，
     光斑淡入开游、WELCOME 只接流光（vgShine，不重播入场避免闪一下重来）、
     TO(0.8s)/南洛'S BLOG(1.2s) 模糊入场，4.5s 后 .is-ready 出面板。
- CSS 要点：光斑 animation 从基类挪进 .is-shown 规则；.vg-skip 动画同样挪进
  .is-shown（幕布期不提示）；reduced-motion 块同步改（无动画时三行 opacity:1）。
- 解锁滚动时 dispatch resize（LiquidText 监听 resize 重量字形蒙版）。
- 探针实测（tmp/vg-timing.cjs）：cover@320ms（早于 load@1505，line2 opacity 0、
  全部动画 none）→ shown@2202（晚于 load，line1=vgShine、line2=vgTextIn+vgShine、
  光斑=vgBgMove）；2.6s 后三行 opacity 全 1、跳过提示 0.55；点普通版全流程通过。

### Liquid Glass 引擎（关键）
- **`backdrop-filter: url(#svgFilter)` 在 Chromium 里确实生效** —— 已用紫块位移测试实证，所以是真折射，不是假的模糊。
- 流程：`sdRoundRect()` 算圆角矩形 SDF → `buildMap()` 生成位移贴图（R/G 通道向内采样偏移，按尺寸+圆角+band+strength 缓存）→ `feImage` + `feDisplacementMap` + `feGaussianBlur` + `feColorMatrix(saturate)` → 写回 `backdrop-filter`。
- **必须写内联 `!important`**：站点原样式大量 `backdrop-filter: … !important` 且带 id 级特异性，用 `[data-lg-on]` 类规则根本压不过（踩过坑，表现为 `bd:"blur(0px)"`）。
- 两类目标：`PRESETS`（点名精修，**带 `force:true`**）+ `AUTO_ROOTS`（`#main-grid` / `.footer` / `#category-bar-wrapper` 里已在用 `backdrop-filter` 的表面自动升级，预算 1600 节点）。
- `force:true` 的意义：角落那几颗 `.float-trigger-btn` 只有 44~48px（1936px²），会被 `MIN_AREA=2600` 挡掉 —— 点名目标必须绕过面积门槛。改完首页玻璃面从 **7 → 17**。
- `MAX_GLASS` 提到 **26**（首页铺满时 17~20 是常态）。
- 空盒子（无背景/无渐变）跳过，避免浪费名额；`data-lg-skip` 可退出。
- 关卡：`prefers-reduced-motion`、`(hover:hover) and (pointer:fine)`、`hardwareConcurrency>2`、`CSS.supports("backdrop-filter","url(#lg-probe)")`；`body.site-lite` 直接 `revertAll()`。
- API：`window.__liquidGlass.{run,reset,stats,register,unregister,rebuild}`。

### 踩坑：`is:inline` 脚本按文档顺序执行
`Layout.astro` 里 `<DragGlass />` 排在导航岛**之前**，所以 `#dg-puck` 的 IIFE 在 `#drag-glass-toggle` 还不存在时就跑了 → `getElementById` 拿到 `null`，开关永久失效（且不报错，最难查）。
**修法：事件委托**（`document.addEventListener("click", e => e.target.closest("#drag-glass-toggle"))`），节点一律**用时再查**，不在启动阶段缓存。以后新组件要操作别处渲染的节点，照这个来。

### 其他坑
- **暗色选择器特异性**：`dark` 类挂在 `<html>` 上，且站点基础规则带 `body.site-promax #id`（比 `.dark #id` 多一个 type）。写暗色覆盖必须 `html.dark body.site-promax #id` 才压得住。
- **主页指示条别用 `currentColor`**：亮色主题下 currentColor 是近黑 → 就是用户看到的「黑条」。改用 `var(--primary)`（主题色）+ 微光，`min-width:9px` 保证 0% 时也是个可见圆点。它兼作阅读进度 + 回到顶部（点击 / hover 提示 / 切页扫光）。
- CDP 截图里「更好的体验」1080P 弹窗会吃掉所有点击，探测脚本必须先关掉它，否则会误判成「按钮没反应」。

### 验证结论（headless Edge + CDP）
- ProMax：岛宽 660（normal 是 1156），导航项 40×40 且 `font-size:0` 去掉文字，logo 标题隐藏改头像，进度 0→50→100% 正常、点击回顶、普通版完全不受影响。

## 两个用户报障的根因定位（"点一次就变白" + "娱乐模式关不掉"）

### A. 「点一次链接后变白」= 高亮的折射玻璃**从来没挂上过**
不是配色问题，也不是玻璃被撤掉 —— 是**注册时机**把整块玻璃弄丢了：
`registerPillGlass()` 在 `moveTo()` 的**同一帧**被同步调用，而那一刻
`pill` 的 `width` 还是 0（`moveTo` 才刚写内联 width）、`getComputedStyle` 读到的
`opacity` 还是 0（0.3s 淡入过渡的起始值）。引擎 `applyGlass` 里
「不可见 / 尺寸 <8」两条门槛直接把它跳过了，**而注册只被调用一次，之后永不重试**
→ 整条高亮永远只剩 CSS 那层底色，看着就是「一块浅色实心胶囊」。
- 修法 1（引擎侧）：`applyGlass` 里 `if (!cfg.force && cs.opacity === "0") return false;`
  —— 显式点名（force）的目标不吃「正在淡入」这一刀。
- 修法 2（组件侧）：`registerPillGlass` 失败按 120ms 重试、上限 14 次（≈1.7s），
  成功清零（还能兜住「引擎比导航脚本晚就绪」的竞态）。
- 验证：探针读 `pill.hasAttribute("data-lg-on")` + `pill.style.backdrop-filter`
  在 `prep` 阶段（页面刚 ready）就应为 `url("#lg-N")`。之前是 `false` / `(none)`。

### B. 「娱乐模式打开后关不掉」= 失败也把按钮标成"已开启"
`RainEffect.astro` 原来在点击处**乐观**加 `.on`，而 `getUserMedia` 是异步且可能失败
（拒绝授权 / 没设备 / 权限弹窗被晾着）；失败分支只加 `.error`，**从没摘掉 `.on`**
→ 按钮显示"开着"，再点又因为 `voiceMode` 仍是 false 而重新申请一次权限。
- 修法：新增 `syncVoiceUi()` 作为「状态 → 界面」唯一出口（`.on` 只由 `voiceMode` 决定，
  新增 `.starting` 表示授权等待中），失败走 `failVoice()` 必回滚；
  `voiceStartToken` 让在途回调作废；8s 超时强制解锁；等待中再点一下 = 取消申请。
- 验证（无头里 `getUserMedia` 必然失败）：改前点击后是 `on error` 并存、`aria-pressed=true`；
  改后只余 `error`、`aria-pressed=false`。要测**成功**路径就在 prep 里 mock
  `getUserMedia` 返回 `new AudioContext().createMediaStreamDestination().stream` → `on → 空 → on` 正确。

### 顺带修正
- 岛底色「白纱」：ProMax 的岛底 alpha 由 0.275 降到 **0.198**
  （`applyGlass` 里对 `body.site-promax` 把 `tint` 再乘 0.72）。注意**岛底色改不动 CSS**——
  它被引擎写成内联 `background-color: … !important`，只能改 `PRESETS.tint`。
- 高亮配色：`sky-200 (186,230,253)` 明度太高，叠在白岛面上读成白 → 全面换成
  `sky-500 (14,165,233) / cyan-300 (103,232,249)`，ProMax 端色 alpha 0.5、基础 0.46、暗色 0.42/0.44。
- 壁纸每次加载随机（有时浅灰白水磨石、有时深色冰湖），**截图对比前先确认背景是否变了**，
  否则很容易把"背景差"误判成"样式差"。

### 字形玻璃（LiquidText）按 WWDC25 的「25」重做观感
基准：用户给了 Apple WWDC25 主视觉 —— **清透厚玻璃字**（灰白身体 / 左上亮边 / 右下柔和灰影），
外加一个 macOS Liquid Glass 的参考实现压缩包（lucasromerodb 那套 SVG 滤镜）。
- **滤镜配方（`#lg-text-refract`）现在三步**：① 低频湍流 → 高斯 → `feComponentTransfer`
  用 gamma 把噪声「压扁」到 0.5 附近，只留稀疏的透镜鼓包（裸湍流会把背景撕烂）；
  ② `feSpecularLighting` 拿同一张噪声的 alpha 当高度图 + 左上点光源 → **镜面高光**，
  这是「玻璃反光」那层，之前一直缺，也是字看着像空心描边的主因；
  ③ 磨砂 → `feDisplacementMap`（**必须磨砂在前**，否则位移被高斯糊平）→ screen 叠高光。
  位移要克制（scale 16），玻璃是「清」的。
- **最大的坑：光带渐变必须映射到「文字那一行」**。`background-image` 默认铺满**元素盒子**，
  而标题元素是整行宽（1014px）、字只占左边 ~200px —— 不校正的话 `linear-gradient` 的
  第一段（本来就最亮）正好全落在字上，退化成一块**死白**，玻璃变白塑料。
  解法：量出 Range 行盒，写 `background-origin: border-box` + `background-size/position`
  到那一行（`background-origin` 必须显式设成 border-box，否则和蒙版的 border-box
  用户空间差一个 padding）。
